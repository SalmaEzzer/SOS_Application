# Administration SOS — réservé

Emplacement réservé à une future interface d’administration. Aucun framework, écran, rôle ni processus de modération n’est présumé. Avant initialisation, définir les utilisateurs, permissions, cas d’usage, technologie web et intégration avec l’API. Les données y seront chargées depuis l’API ; pas de connexion directe à PostgreSQL depuis le navigateur.
